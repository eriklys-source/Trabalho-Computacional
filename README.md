# Trabalho Computacional - Sinais e Sistemas

Projeto desenvolvido em Python para a disciplina de Sinais e Sistemas da UFERSA.

## Conteúdo do projeto

- Energia de sinais
- Transformações temporais
- Modulação AM
- Convolução
- Resolução de EDOs
- Plotagem de gráficos com Matplotlib

## Bibliotecas utilizadas

- NumPy
- Matplotlib
- SciPy
- SymPy
